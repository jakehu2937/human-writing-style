# 中文示例

沿用 SKILL.md 的共同规则，写成本人平时会说的话。

| 拗口或多余 | 自然表达 |
| --- | --- |
| 我希望能够进一步提升自身在数据分析方面的能力。 | 我想提高数据分析能力。 |
| 由于样本数量存在一定的局限性，因此结论的适用范围可能受到影响。 | 样本较少，结论可能不适用于其他情况。 |
| 数据团队进行了对权限配置的检查。 | 数据团队检查了权限配置。 |
| 值得注意的是，这一结果充分体现了沟通的重要性。 | 这说明沟通很重要。 |
| 需要强调的是，这仅仅是一个初步的想法，并不代表最终的决定。 | 这是初步想法。 |

## 句式示例

| 句式 | 原文 | 改后 |
| --- | --- | --- |
| 三项近义堆叠 | 我想不断成长、持续进步、实现自我提升。 | 我想有所进步。 |
| 连续排比 | 我检查了数据。我检查了代码。我检查了结果。 | 我检查了数据、代码和结果。 |
| 假对比 | 这不只是有用，更是必不可少。 | 这必不可少。 |
| 设问自答 | 结果如何？我们按时完成了。 | 我们按时完成了。 |
| 双逗号插入语 | 这个方法，在我看来，更容易使用。 | 我觉得这个方法更容易使用。 |
| 破折号插入语 | 样本很小——但仍然有用。 | 样本很小，但仍然有用。 |

“模型使用年龄、收入和负债”中的三个输入都有实际含义，应完整保留。

## 其他需要识别的变体

| 类型 | 检查示例 |
| --- | --- |
| 假对比 | “重点不在 X，而在 Y”“没有 X，没有 Y，只有 Z”“问题不在 X。真正的问题是 Y。” |
| 递进升格 | 连续“更……”、近义四字词堆叠、每段都套“首先／其次／最后” |
| 套话与升华 | “在当今……时代”“值得注意的是”“赋能”“具有重要意义”，以及没有依据的结尾展望 |
| 金句碎片 | “那么问题来了”“一个字：X”，以及连续断行制造强调 |
| 翻译腔 | 层叠的“对于……来说”“进行……的开展”“使得……得以……” |

## 中文表达与含义

按中文习惯组织句子。拆开层叠定语，把动作从抽象名词中还原出来。上下文清楚时自然省略主语，简体或繁体沿用用户的选择。

“权限恢复后，流程可以运行”保留了可运行状态；改成“流程已运行”就增加了事实。“预计每年节省 120 小时”也不能改成已经实现的节省。

“研究表明”需要对应材料，不能用来替代同样缺少来源的“业内普遍认为”。缩写含义不明确时保留原文。
