# 中文示例

沿用 SKILL.md 的共同规则，写成本人平时会说的话。

| 拗口或多余 | 自然表达 |
| --- | --- |
| 我希望能够进一步提升自身在数据分析方面的能力。 | 我想提高数据分析能力。 |
| 由于样本数量存在一定的局限性，因此结论的适用范围可能受到影响。 | 样本较少，结论可能不适用于其他情况。 |
| 数据团队进行了对权限配置的检查。 | 数据团队检查了权限配置。 |
| 值得注意的是，这一结果充分体现了沟通的重要性。 | 这说明沟通很重要。 |
| 需要强调的是，这仅仅是一个初步的想法，并不代表最终的决定。 | 这是初步想法。 |

## 句式示例

| 句式 | 原文 | 改后 |
| --- | --- | --- |
| 三项近义堆叠 | 我想不断成长、持续进步、实现自我提升。 | 我想有所进步。 |
| 连续排比 | 我检查了数据。我检查了代码。我检查了结果。 | 我检查了数据和代码，然后核对结果。 |
| 假对比 | 这不只是有用，更是必不可少。 | 这必不可少。 |
| 设问自答 | 结果如何？我们按时完成了。 | 我们按时完成了。 |
| 双逗号插入语 | 这个方法，在我看来，更容易使用。 | 我觉得这个方法更容易使用。 |
| 破折号插入语 | 样本很小——但仍然有用。 | 样本很小，但仍然有用。 |

“模型使用年龄、收入和负债”中的三个输入都有实际含义，应完整保留。
